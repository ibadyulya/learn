## Вопрос 1
Дай определение чистой функции (два условия). Почему из чистоты следуют
тестируемость, кэшируемость и безопасная параллельность?

## Вопрос 2
Какие из этих функций чистые, а какие нет и почему?
```ts
const a = (x: number) => x * 2;
const b = (arr: number[]) => arr.sort();
const c = () => Date.now();
const d = (arr: number[]) => [...arr].sort();
```

## Вопрос 3
Почему неизменяемость важна для реактивности React/Redux? Что сломается, если
мутировать состояние напрямую (`state.items.push(x)`)?

## Вопрос 4
Перепиши императивный код декларативно (без цикла и мутаций):
```ts
let result = [];
for (const u of users) {
  if (u.active) result.push(u.name.toUpperCase());
}
```

## Вопрос 5

удобно.

## Вопрос 6

## Вопрос 7

`compose(f, g, h)(x) === f(g(h(x)))`.

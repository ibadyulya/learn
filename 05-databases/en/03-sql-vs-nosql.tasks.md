## Question 1
How does a relational DB differ from a non-relational one by data model? Name a
strength and a weakness of SQL.

## Question 2
Is "NoSQL" one type of DB? List the families and one scenario each.

## Question 3
What are schema-on-write and schema-on-read? Which approach does SQL take, which do
document NoSQL, and what's good/bad about each?

## Question 4
What do ACID and BASE mean? How does this relate to the CAP theorem?

## Question 5
For which task would you pick SQL, and for which a document NoSQL? One example each.

## Question 6
What is polyglot persistence? Give an example stack of 2–3 different stores in one
product.

## Question 7
The interviewer: "SQL doesn't scale, you should take Mongo." How is this phrase
wrong/superficial?

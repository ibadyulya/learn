## Commit message convention

Every commit message follows a **simple prefix** pattern:

```
<Prefix>: <short summary>
```

**Rules:**
- Start with one of the prefixes below, followed by `: ` and a short summary.
- Summary is in the imperative mood, capitalized, no trailing period.
- Keep the summary line under ~60 characters.
- Add an optional blank line + body only when more detail is genuinely needed.

**Allowed prefixes:**

| Prefix | Use for |
|--------|---------|
| `Add:` | New notes, topics, or files |
| `Update:` | Changes to existing notes/content |
| `Fix:` | Corrections — typos, wrong info, broken links |
| `Docs:` | README or meta/repo documentation |
| `Refactor:` | Reorganizing or restructuring without changing meaning |

**Examples:**

```
Add: notes on event loop and microtasks
Update: expand React reconciliation section
Fix: correct Big-O for hash map lookup
Docs: add table of contents to README
```

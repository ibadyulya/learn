## Вопрос 1 — база
Назови главное **механическое** отличие загрузки CJS и ESM (не про синтаксис).
Почему из этого следует, что `require` можно писать внутри `if`, а `import` —
нельзя?

## Вопрос 2 — живые связи
```js
// counter.cjs / counter.mjs
export let count = 0;          // в CJS: module.exports.count = 0
export function inc() { count++; }
```
Импортёр вызвал `inc()` и снова прочитал `count`. Что выведет в CJS и что в ESM?
Почему?

## Вопрос 3 — интероп
Можно ли в CJS-файле сделать `const x = require('./esm-module.mjs')`? А наоборот
— в ESM импортировать CJS? Как обойти запрещённое направление?

## Вопрос 4 — определение формата
Есть файл `index.js` без каких-либо `.mjs`. От чего зависит, как Node его
прочитает — CJS или ESM? Перечисли сигналы по приоритету.

## Вопрос 5 — event loop
Почему классическая «гонка на верхнем уровне» `setTimeout(0)` vs `setImmediate`
чаще склоняется к таймеру именно в ESM? Изменится ли гарантия внутри
I/O-колбэка?

## Вопрос 6 — __dirname

# Типы, приведение и равенство — разборы

> 🌐 English version: [07-types-coercion-equality.answers.md](../en/07-types-coercion-equality.answers.md)

---

## Вопрос 1
Примитивы: `string`, `number`, `boolean`, `null`, `undefined`, `symbol`, `bigint`.
Примитив копируется **по значению** (переменные независимы); объект — **по ссылке**
(две переменные указывают на один объект, изменение видно обеим).

## Вопрос 2
Два объектных литерала — **два разных объекта в памяти**; `===` для объектов
сравнивает **ссылки**, а они разные → `false`. Сравнить по содержимому: вручную по
полям, через `JSON.stringify(a) === JSON.stringify(b)` (осторожно с порядком ключей
и типами), или глубоким сравнением из библиотеки (lodash `isEqual`).

## Вопрос 3
`===` — равно только при **совпадении типа и значения**, без приведения. `==`
приводит типы перед сравнением. Примеры сюрпризов:
```ts
0 == '';      // true — оба приводятся к 0
[] == ![];    // true — ![]→false→0, []→''→0, 0==0
'' == '0';    // false — обе строки, приведения нет
```

## Вопрос 4
Falsy (8): `false`, `0`, `-0`, `0n`, `''`, `null`, `undefined`, `NaN`.
Из списка truthy: **`'0'`, `[]`, `{}`, `'false'`** (непустые строки и любые объекты/
массивы истинны). Falsy: `''`, `0`.

## Вопрос 5
```ts
1 + '2'      // '12'  — есть строка → конкатенация, 1→'1'
'5' - 2      //  3    — у "-" нет строковой версии → '5'→5
1 + 2 + '3'  // '33'  — слева направо: 1+2=3, затем 3+'3'='33'
'3' + 2 + 1  // '321' — '3'+2='32', затем '32'+1='321'
```
Ключ: `+` строковый при строке и считается слева направо.

## Вопрос 6
`NaN` по стандарту IEEE-754 «не равен ничему», в том числе самому себе, поэтому
`NaN === NaN` — `false`. Проверять — **`Number.isNaN(x)`** (не глобальный `isNaN`,
который сперва приводит аргумент и врёт: `isNaN('foo') === true`). Ещё вариант —
`Object.is(x, NaN)`.

## Вопрос 7
- **`undefined`** — значение не задано: необъявленное свойство, пропущенный
  аргумент, `return` без значения, необъявленная переменная.
- **`null`** — намеренная «пустота», ставит разработчик.
`null == undefined` → **true** (спец-правило `==`); `null === undefined` → **false**
(разные типы).

## Вопрос 8
`Object.is` почти как `===`, но:
1. `Object.is(NaN, NaN)` → **true** (у `===` → false);
2. `Object.is(0, -0)` → **false** (у `===` → true).
В остальном совпадает с `===`.

# Итераторы и генераторы — разборы

> 🌐 English version: [08-iterators-generators.answers.md](../en/08-iterators-generators.answers.md)

---

## Вопрос 1
- **Iterable** — объект с методом `[Symbol.iterator]()`, возвращающим итератор
  («меня можно перебирать»).
- **Iterator** — объект с методом `next()`, который на каждом вызове возвращает
  `{ value, done }`: `value` — текущий элемент, `done: true` — когда закончилось.
Iterable отдаёт итератор, итератор выдаёт элементы по одному.

## Вопрос 2
`for...of`, спред `[...x]`, деструктуризация массива `const [a, b] = x`,
`Array.from(x)`, `new Set(x)` / `new Map(x)`, `Promise.all(x)`, `yield*`. Все они
внутри дёргают `Symbol.iterator` и крутят `next()`.

## Вопрос 3
У массива есть встроенный `Symbol.iterator`, у обычного объекта — **нет**, поэтому
`for...of` по `{}` кидает `is not iterable`. Перебрать объект: `for...in` (по ключам,
осторожно с наследованными), либо через итерируемые «представления» —
`Object.keys(o)`, `Object.values(o)`, `Object.entries(o)` + `for...of`.

## Вопрос 4
`function*` объявляет генератор, `yield` — точка, где выполнение **замирает**, отдав
значение. В отличие от обычной функции (бежит до `return` за один заход), генератор
исполняется **порциями**: каждый `next()` продолжает с последнего `yield`, сохраняя
локальное состояние. Функция как бы ставится на паузу.

## Вопрос 5
```ts
function* range(from: number, to: number, step = 1) {
  for (let i = from; i <= to; i += step) yield i;
}
[...range(0, 10, 2)];   // [0, 2, 4, 6, 8, 10]
```

## Вопрос 6
```ts
function* naturals() { let n = 1; while (true) yield n++; }
```
`while (true)` не завешивает рантайм, потому что генератор **ленивый**: тело
крутится только на `next()` и **останавливается на `yield`** до следующего запроса.
Пока берёшь конечное число (`g.next()` N раз или `for...of` с `break`), вычисляется
ровно N элементов, а не бесконечность.

## Вопрос 7
```ts
const range = {
  from: 1, to: 3,
  *[Symbol.iterator]() {
    for (let i = this.from; i <= this.to; i++) yield i;
  }
};
[...range];   // [1, 2, 3]
```
Генератор в `[Symbol.iterator]` короче ручного `next()` и сам реализует протокол.

## Вопрос 8
**Async-итераторы** нужны, когда элементы приходят **асинхронно** (чтение потока/
файла по кускам, страницы API, сообщения из очереди). Объявляются `Symbol.asyncIterator`
/ `async function*` с `yield`, каждый шаг — промис. Перебор — цикл **`for await (const
x of source)`**. Node-стримы асинхронно итерируемы.

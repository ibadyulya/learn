# Типовые алгоритмы — разборы

## Вопрос 1
**Два указателя** — два индекса двигаются по структуре (навстречу или в одном темпе),
заменяя перебор пар. Класс задач: **отсортированный массив**, пара/тройка с условием,
палиндром, слияние. Пример — пара с суммой `target` на отсортированном массиве: указатели с
краёв, сумма мала → сдвинуть левый вправо, велика → правый влево. Вместо O(n²) перебора —
**O(n)**.

## Вопрос 2
**Скользящее окно** — поддерживаем подотрезок (окно), двигая границы и **обновляя** результат
инкрементально, вместо пересчёта с нуля. Экономит: наивный пересчёт каждого окна — **O(n·k)**
или O(n²), окно — **O(n)**. Сигнал: «непрерывный подмассив/подстрока», «окно длины k»,
«самая длинная подстрока с условием».

## Вопрос 3
- **BFS** — **очередь**, обход **по уровням** (сначала ближайшие). Естественен для
  **кратчайшего пути** в невзвешенном графе, «минимум шагов».
- **DFS** — **стек/рекурсия**, обход **вглубь**. Естественен для «обойти всё», компоненты
  связности, поиск пути, топосортировка.
BFS находит кратчайший путь, потому что расширяется **волной по уровням**: до узла на
расстоянии d добирается **раньше**, чем до узла на d+1 → первый раз, когда достигли цель, —
это минимальное число рёбер.

## Вопрос 4
**Динамическое программирование** применимо, когда: (1) **перекрывающиеся подзадачи** — одни
и те же подзадачи решаются многократно (есть что кэшировать); (2) **оптимальная
подструктура** — оптимум задачи строится из оптимумов подзадач. Тогда запоминаем решения
подзадач (мемоизация/табуляция) и не пересчитываем.

## Вопрос 5
Наивный `fib(n) = fib(n-1) + fib(n-2)` порождает **дерево вызовов**, где одни и те же
`fib(k)` считаются **многократно** (экспоненциально много раз) → **O(2ⁿ)**. **Мемоизация**
кэширует результат каждого `fib(k)` при первом вычислении; повторные вызовы берут из кэша за
O(1). Каждое значение считается **один раз** → всего **O(n)** вычислений.

## Вопрос 6
**Жадный** алгоритм на каждом шаге берёт локально лучший выбор. Работает не всегда — только
если локальный оптимум гарантированно ведёт к глобальному (свойство, которое надо доказать).
Ломается, например, на **размене монет нестандартным набором**: монеты {1, 3, 4}, сумма 6.
Жадно: 4 + 1 + 1 = 3 монеты. Оптимально: 3 + 3 = **2 монеты**. Здесь нужен **DP**, жадность
даёт неоптимум.

## Вопрос 7
Приём — **скользящее окно** + множество/хеш символов в окне. Двигаем правую границу, добавляя
символы; при повторе сдвигаем левую границу, убирая символы, пока повтор не исчезнет;
максимум длины окна — ответ. Каждый символ добавляется и удаляется не более раза →
**O(n)** по времени, O(k) по памяти (k — размер алфавита).
